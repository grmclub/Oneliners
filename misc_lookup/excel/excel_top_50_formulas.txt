## compare values of two columns

For side-by-side exact row checks: Use simple logical comparisons like =A2=B2 or =IF(A2=B2, "Match", "Different").

1. Quick True/False Check (Exact Match)
Checks if the cell in Column A directly matches the cell in Column B on the same row (case-insensitive).
=A2=B2

2. Custom Status Label ("Match" vs "Mismatch")
Returns a clean, readable text label for row-by-row comparisons.
=IF(A2=B2, "Match", "Mismatch")

3. Case-Sensitive Exact Match
=IF(EXACT(A2, B2), "Match", "Mismatch")

4. Compare Numbers with Tolerance (Ignoring Minor Differences)
Useful for financial reconciliations where minor rounding differences (e.g., floating point decimals or cents) should still count as matches.
=IF(ABS(A2-B2)<=0.01, "Match", "Difference")

5. Highlight Differences Without Formulas (Conditional Formatting)
To visually highlight side-by-side differences in color across your dataset:
    1. Select the two columns you want to compare (e.g., A2:B100).
    2. Go to Home $\rightarrow$ Conditional Formatting $\rightarrow$ Highlight Cells Rules $\rightarrow$ Duplicate Values.
    3. Change the dropdown from Duplicate to Unique.
    4. Choose your formatting (e.g., Light Red Fill) and click OK.

6. Keyboard Shortcut: Row Difference Selection
Quickly select all cells in Column B that differ from Column A without writing formulas:
    1. Highlight the rows in both columns (e.g., A2:B100).
    2. Press Ctrl + \ (Control + Backslash).
    3. Excel will immediately select only the cells in Column B that do not match Column A. You can then fill them with a highlight color.

When row order differs or datasets are unsorted: XLOOKUP is ideal because it searches the entire target column regardless of row order.

Extra spaces and blank cells are the most common reasons formula comparisons fail when two entries look identical. 
Here is how to handle both issues effectively.

1. Cleaning Extra Spaces

To eliminate trailing spaces, leading spaces, and non-breaking spaces (often copied from web pages or database exports), wrap your cell references in TRIM() and CLEAN():

    Basic Space Cleaning (TRIM): Removes leading, trailing, and double spaces between words.
    =IF(TRIM(A2)=TRIM(B2), "Match", "Mismatch")

Advanced Web Space Cleaning (TRIM + CLEAN + SUBSTITUTE): Replaces stubborn non-breaking spaces (ASCII character 160) with standard spaces, then strips them.
    =IF(TRIM(CLEAN(SUBSTITUTE(A2, CHAR(160), " ")))=TRIM(CLEAN(SUBSTITUTE(B2, CHAR(160), " "))), "Match", "Mismatch")

2. Custom Status Label ("Match" vs "Mismatch")
Returns a clean, readable text label for row-by-row comparisons.

    Formula in C2:
    =IF(A2=B2, "Match", "Mismatch")

3. Case-Sensitive Exact Match
Standard formulas treat "APPLE" and "apple" as identical. To enforce exact case sensitivity:

    Formula in C2:
    =IF(EXACT(A2, B2), "Match", "Mismatch")

4. Compare Numbers with Tolerance (Ignoring Minor Differences)
Useful for financial reconciliations where minor rounding differences (e.g., floating point decimals or cents) should still count as matches.

    Formula in C2 (e.g., tolerance of 0.01):
    =IF(ABS(A2-B2)<=0.01, "Match", "Difference")

5. Highlight Differences Without Formulas (Conditional Formatting)
To visually highlight side-by-side differences in color across your dataset:

    Select the two columns you want to compare (e.g., A2:B100).
    Go to Home → Conditional Formatting → Highlight Cells Rules → Duplicate Values.
    Change the dropdown from Duplicate to Unique.
    Choose your formatting (e.g., Light Red Fill) and click OK.

6. Keyboard Shortcut: Row Difference Selection
Quickly select all cells in Column B that differ from Column A without writing formulas:

    Highlight the rows in both columns (e.g., A2:B100).
    Press Ctrl + \ (Control + Backslash).
    Excel will immediately select only the cells in Column B that do not match Column A. You can then fill them with a highlight color.

simple VBA macro that strips leading/trailing spaces, removes extra spaces between words, and deletes non-printable or non-breaking web characters (like CHAR(160)) across all currently selected cells.

Sub CleanAndTrimSelection()
    Dim cell As Range
    Dim calcState As XlCalculation
    
    ' Optimize performance during execution
    On Error Resume Next
    calcState = Application.Calculation
    Application.Calculation = xlCalculationManual
    Application.ScreenUpdating = False
    
    ' Loop through every non-empty cell in user selection
    For Each cell In Intersect(Selection, Selection.Parent.UsedRange)
        If Not IsEmpty(cell.Value) And Not cell.HasFormula Then
            ' 1. Replace non-breaking web space (ASCII 160) with standard space
            ' 2. Clean non-printable ASCII characters (0-31)
            ' 3. Trim extra leading, trailing, and duplicate spaces
            cell.Value = Application.WorksheetFunction.Trim( _
                            Application.WorksheetFunction.Clean( _
                                Replace(cell.Value, Chr(160), " ") _
                            ) _
                         )
        End If
    Next cell
    
    ' Restore settings
    Application.Calculation = calcState
    Application.ScreenUpdating = True
    On Error GoTo 0
    
    MsgBox "Selected cells cleaned successfully!", vbInformation, "Clean Complete"
End Sub

How to Install and Run It

1.Open the VBA Editor:
Press Alt + F11 in Excel to open the Visual Basic Editor.
2.Insert a New Module:
Click Insert $\rightarrow$ Module in the top menu bar.
3.Paste the Code:
Copy the VBA code above and paste it directly into the code window that appears.
4.Run the Macro:
    1. Select the range of cells you want to clean in your worksheet.
    2. Press Alt + F8, select CleanAndTrimSelection, and click Run.
=====================
What Makes This Macro Safe & Fast
    • Skips Formulas: It leaves formula cells intact so it won't break any =SUM() or lookup logic in your sheet.
    • Handles Large Ranges Fast: It pauses screen updating and switches calculation mode off while running, so it won't freeze Excel if you select entire columns.
    • Cleans Web Exports: Automatically targets Chr(160) (non-breaking spaces common in web pastes) which standard TRIM() often misses.
