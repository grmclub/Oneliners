* sort-large-files-efficiently 

##By specifying –parallel=4, we instruct the sort command to divide the input data into multiple chunks and sort them in parallel using four threads.
#sort --parallel=4 data.txt > sorted_parallel_data.txt

##Use split tool to break data.txt into smaller files:
$ split -l 10000 -d data.txt splitdata

##sort the splitdata files:
$ for X in splidata*; do sort -t'|' -k2 -n < $X > final-$X; done

##merge the sorted files into one large file:
$ time sort -t'|' -k2 -n -m final-splitdata* > sorted_split_data.txt

$ time LC_ALL=C sort data.txt > sorted_data_c_locale.txt

##To periodically check a file size simultaneously across multiple Linux servers

Option 1: Using watch and GNU Parallel via SSH
run a parallel SSH command wrapped in a watch loop from your local machine to poll all servers at the same interval.

watch -n 5 "parallel -S user@server1,user@server2,user@server3 'stat -c \"%n: %s bytes (%y)\" /path/to/file'"


Option 2: Using a Bash Loop with Background (&) and wait inside watch

If parallel is not installed, you can trigger concurrent ssh jobs in a bash script loop and collect their outputs:
bash
watch -n 5 '
for host in server1 server2 server3; do
  ssh -n user@$host "stat -c \"$host -> %n: %s bytes\" /path/to/file" &
done
wait
'
