1. print a newline in Bash
-e flag to enable the interpretation of backslash escapes

#!/bin/bash
echo -e "First Line\nSecond Line"

⚠️ Best Practice: Use printf for Portability
If you are writing a script that needs to run reliably across different operating systems (like Linux, macOS, and BSD), avoid echo entirely. The echo command behaves inconsistently across platforms and shell environments. 

Instead, the industry-standard recommendation is to use printf, which honors \n by default across all systems. 

printf "Hello\nWorld\n"

3. If-Else Condition

#!/bin/bash
read -p "Enter a number: " num

if [ $num -gt 10 ]; then
  echo "Greater than 10"
else
  echo "10 or less"
fi

4. For Loop

#!/bin/bash

do
  echo "Number: $i"
done

5. While Loop

#!/bin/bash
count=1
while [ $count -le 5 ]
do
  echo "Count is $count"
  ((count++))
done
